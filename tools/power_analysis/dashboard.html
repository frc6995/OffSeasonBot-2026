How to get the log files off the robot
  1. Make sure logging is on: HootLogging.kEnabled is true in the robot code that was deployed. It logs from robot program start until the program exits.
  2. After the match, copy the newest folder of .hoot files from the roboRIO. They are on the USB stick in /u/logs, or in /home/lvuser/logs without one. There is one file per CAN bus.
  3. Convert each file with owlet, which ships with Phoenix Tuner X and AdvantageScope. -e 5 keeps only the enabled part of the log plus 5 s either side, which makes the files much smaller.
    owlet UpperBus.hoot UpperBus.wpilog -f wpilog -e 5
  4. Drop every converted .wpilog from that match onto this page together.

The robot code only logs supply current and supply voltage for each Talon FX (Phoenix does this in its own thread, off the robot loop), plus the robot, flywheel and intake states when they change. Totals leave out the roboRIO, radio and cameras, typically another 5–10 A.
